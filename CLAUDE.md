# Claude instruction

- Antworte auf Deutsch, sofern der Nutzer keine andere Sprache ausdrücklich verlangt.
- Verwende klare, kurze deutsche Erläuterungen für Feedback, Zusammenfassungen und Hinweise.
- Behalte technische Begriffe, Befehle und Funktionsnamen in ihrer Originalschreibweise, falls sie im Code oder in CLI-Ausgaben so benannt sind.
- Bei Code-Review oder Erklärungen: deutsche Überschriften und Bullet-Points, aber keine unnötigen Übersetzungen fachlicher Bezeichnungen.
- Wenn der Nutzer etwas in einer anderen Sprache verlangt, folge genau dieser Sprache.
